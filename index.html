數字看澳門

一個用數據重新認識澳門的非官方網站。統計故事、城市統計與數據目錄取自澳門政府數據開放平台；天氣與空氣觀測取自地球物理氣象局。

資料來源及數據更新

天氣及空氣觀測在頁面開啟時讀取，並每 5 分鐘重試；排程每小時更新備用快照。統計局發布時間表每日核對，只用來顯示預定日期；統計數值只從政府數據開放平台取得。

資料流程：統計局公布 → 政府數據開放平台提供新一期 → 本站核對並更新快照。統計數值的每日自動核對須先取得平台 API 金鑰；在此之前不會自動更換數字。數據目錄及地點資料目標每週檢查，目前仍須人工更新。實際執行情況、資料期間及快照時間，以頁面標示為準。

統計卡片使用網站已儲存資料；不代表來源網站目前的最新版本。
